If you build 100 confidence intervals at the 95% level, how many will contain the true mean? In this simulation, each horizontal line is a confidence interval from a fresh sample. Green intervals cross the vertical line at the true mean. Click **New samples** a few times and watch the count change. [Open the confidence interval visualization](/visualizations/confidence-interval-coverage/).

Now click **Simulate 1000 runs**. Each run counts how many of its 100 intervals contain the true mean. The counts vary from run to run, while the average coverage settles close to 95%. The 95% describes how often this procedure produces an interval that contains the fixed mean when we repeat the sampling.

Keep the same samples and switch from 95% to 99%. The intervals get wider, so they cover the true mean more often across repeated samples. [Confidence intervals in the review notes](/posts/point-estimation-confidence-intervals-and-hypothesis-testing/#confidence-intervals).
