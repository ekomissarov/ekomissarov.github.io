Why the sample proportion hits the Cramér–Rao bound

X₁, …, Xₙ are independent Bernoulli(p) trials with 0 < p < 1. Both X₁ (a single trial) and p̂ = X̄ₙ are unbiased for p. The Fisher information of one trial is 1/(p(1−p)), so no unbiased estimator from n trials can have variance below p(1−p)/n. The vertical scale is fixed, so you can watch the blue curve sink as n grows.
