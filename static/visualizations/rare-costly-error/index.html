The rarer the error, the costlier it is

Consider the estimator Zₙ of the target value 0 that equals n with probability 1/n and 0 otherwise. As n grows the error becomes rarer, so Zₙ → 0 in probability. But when it does occur it equals n, and the mean squared error grows with n.
