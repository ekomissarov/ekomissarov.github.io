Variance estimators: divisor n versus n − 1

Every simulation draws one sample of size n from N(0, 1) and computes both estimators from that same sample. The true variance is σ² = 1. Both histograms use the same bins and the same axes, so the shift and the spread can be compared directly.

Divisor n

σ̂² = Σ(Xᵢ − X̄)² / n

Divisor n − 1

S² = Σ(Xᵢ − X̄)² / (n − 1)

At n = 2, both exact densities rise without bound as the variance estimate approaches zero. The top of each curve is clipped to keep the histograms readable.
