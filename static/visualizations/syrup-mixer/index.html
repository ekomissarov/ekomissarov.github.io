Syrup Mixer

Interactive Syrup Mixer

Sliders set each source's concentration, valves set each flow rate. The bucket holds the flow-weighted mixture of the two.

Concentration Calculation

C = (C1 × Q1 + C2 × Q2) / (Q1 + Q2)
C1, C2 = source concentrations Q1, Q2 = relative flow rates, 0.0 to 10.0 units

Controls

Drag the sliders and dials in the picture, or use these inputs.
